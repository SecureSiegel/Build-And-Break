# Advanced 2 C++: From Functions to Objects

Welcome back! In Phase 1 we learned how to plan a program and build it with variables, decisions, loops, functions, arrays, and files. In this course, I will help you take the next step: organize a program around data and the objects that work with that data.

## How I will teach this course

Work through the lessons in order. In every lesson, we will:

1. Read the goal and agree on what the program or class should do.
2. Sketch the data and the steps before coding.
3. Follow the guided steps and run small tests as we build.
4. Try the practice tasks and explain our design choices.
5. Use the check-for-understanding questions before moving forward.

Errors are part of learning. We will read compiler messages, test boundary cases, and correct mistakes instead of assuming old sample code is always right.

## Course sequence

| Lesson | What we will learn | Source-project connection |
|---|---|---|
| [01 - Review, Program Design, and Debugging](Lesson-01-Review-Program-Design-and-Debugging.md) | Plan the problem, specify input/output, build, test, document, and debug |
| [02 - Arrays, Functions, and References](Lesson-02-Arrays-Functions-and-References.md) | Pass arrays to functions, use bounds safely, and change values through references |
| [03 - Pointers and Addresses](Lesson-03-Pointers-and-Addresses.md) | Understand addresses, dereferencing, null pointers, and safe pointer use |
| [04 - Classes and Encapsulation](Lesson-04-Classes-and-Encapsulation.md) | Design a class with private state, public operations, and constructors |
| [05 - Header Files, Implementation, and Client Code](Lesson-05-Header-Implementation-and-Client-Code.md) | Separate a class declaration, definitions, and the code that uses it |
| [06 - Building Useful Classes](Lesson-06-Building-Useful-Classes.md) | Model inventory or sports data, validate state, and calculate derived values |
| [07 - Object Lifetimes and Destructors](Lesson-07-Object-Lifetimes-and-Destructors.md) | Understand constructors, destructors, scope, and resource ownership |
| [08 - Linked Lists and Dynamic Data](Lesson-08-Linked-Lists-and-Dynamic-Data.md) | Connect nodes, traverse a list, and reason about insertion, removal, and cleanup |
| [09 - Event-Driven Programs and the Final Project](Lesson-09-Event-Driven-Programs-and-Final-Project.md) | Understand GUI events, plan a small object-based project, test it, and present it |

## What I want you to be able to do

By the end, you should be able to explain how an object protects its data, how its functions use that data, how separate source files fit together, and how a collection of dynamically connected nodes differs from an array. I also want you to be able to test and explain your own design with confidence.
